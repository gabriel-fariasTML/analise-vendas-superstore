## Análise de Vendas — Superstore Dataset
Projeto de análise exploratória de dados de vendas de uma rede de varejo americana, desenvolvido com Python.

## Ferramentas utilizadas
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## O que foi analisado
- Limpeza e tratamento dos dados
- Total de vendas e lucro
- Vendas por categoria
- Lucro por região
- Evolução mensal das vendas
- Participação das categorias

## Principais insights
- A categoria **Technology** lidera em faturamento
- A região **West** é a mais lucrativa
- As vendas apresentaram crescimento consistente ao longo do período
